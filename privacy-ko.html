애플리케이션 및 게시자

IPTV Orbit Player는 Samsung Tizen TV용 무료 오픈 소스 미디어 플레이어입니다. 사용자가 이용 권한을 가진 Xtream 호환 서비스에 연결합니다. 게시자는 Muhammet Kamil Aksay입니다. 이 애플리케이션은 제공업체의 채널, 콘텐츠 구독 또는 미디어 서버를 제공하지 않습니다.

선택 기능인 Hesapsız yerel örneği izle는 계정이나 인터넷 연결 없이 앱에 포함된 자체 제작 MIT 라이선스 동영상을 재생합니다. 길이는 120초이며 모든 데모 목록 항목이 동일한 유한 길이의 파일을 사용합니다. 이 항목들은 실제 실시간 방송이나 영화·시리즈 카탈로그가 아닙니다. 파일에는 합성 AAC 테스트음 트랙 두 개가 있고 내장 자막은 없습니다. 앱의 실제 사용자 인터페이스 언어는 터키어이며 이 한국어 방침이 한국어 앱 인터페이스를 의미하지는 않습니다.

TV에 저장되는 정보

자동 로그인과 사용자가 명시적으로 선택한 설정을 유지하기 위해 TV의 앱 전용 로컬 저장소를 사용합니다.

정보목적과 저장 방식
서버 주소, 사용자 이름 및 계정 비밀번호로그인 성공 후 자동 로그인을 위해 akis.credentials.v1에 저장됩니다. 암호화된 보관함이 아닌 평문으로 저장됩니다.
HLS/TS 형식 설정akis.format에 저장됩니다.
숨기거나 잠근 카테고리, 화면 비율 및 탐색 간격akis.preferences.v1에 저장됩니다. 카테고리 설정은 서버 주소와 사용자 이름으로부터 만든 비암호학적 계정 범위 식별자에 연결됩니다.
PIN 검증 기록설정과 함께 무작위 솔트 및 PBKDF2-SHA256 파생 정보로 저장됩니다. PIN 자체를 평문으로 저장하지 않습니다. 카테고리 PIN은 제공업체 비밀번호나 TV 계정을 보호하는 암호화 보관함을 대신하지 않습니다.

앱은 시청 기록, 최근 시청 목록, 검색 기록 또는 이어보기 위치를 영구 저장하지 않습니다. 검색 결과, 편성 정보 및 임시 카테고리 잠금 해제 권한은 실행 메모리에서 처리됩니다. 재생 중 필요한 일시적인 상태를 영구 시청 기록으로 변환하지 않습니다.

네트워크를 통해 전송되는 정보

앱은 사용자가 선택한 제공업체에 직접 연결합니다. 인증과 카탈로그·편성 정보 요청에는 서버 주소, 사용자 이름 및 비밀번호가 사용됩니다. Xtream API 요청의 URL 쿼리 또는 미디어 요청 경로에 인증 정보가 포함될 수 있습니다. 요청한 카테고리, 방송 또는 에피소드의 식별자도 필요에 따라 전송됩니다. 검색어 일치는 앱 내부에서 수행되며 입력한 검색어를 게시자의 분석 서비스로 전송하지 않습니다.

채널 로고, 표지 이미지, 동영상, 오디오, 자막, HLS 재생목록·세그먼트·키는 제공업체가 지정한 미디어·이미지 서버 또는 해당 서버가 리디렉션하는 제3자 서버에서 제공될 수 있습니다. 이들 서버는 네트워크 IP 주소, 요청한 리소스 및 일반적인 연결 정보를 볼 수 있습니다. 제공업체는 요청한 콘텐츠에 대한 자체 로그를 보관할 수 있습니다. 앱이 로컬 시청 기록을 남기지 않는다고 해서 제공업체나 TV 운영체제가 로그를 남기지 않는 것은 아닙니다.

앱에는 게시자가 운영하는 분석·텔레메트리, 광고, 행동 프로파일링 또는 앱 계정 서버가 설정되어 있지 않습니다. 저장된 제공업체 계정을 게시자에게 전송하기 위한 별도 엔드포인트도 없습니다. Samsung 플랫폼 서비스와 사용자가 선택한 제공업체의 정보 처리는 각 서비스의 정책과 조건을 따릅니다. 로컬 데모 재생은 제공업체 요청을 필요로 하지 않습니다.

연결 및 로컬 보안

제공업체에서 지원하는 경우 HTTPS를 사용하세요. 사용자가 명시적으로 http:// 주소를 입력하면 HTTP가 사용될 수 있으며 전송 연결은 암호화되지 않습니다. TLS 연결이 실패했을 때 앱이 자동으로 HTTP로 낮추지 않습니다. 인증 정보가 URL에 포함될 수 있으므로 네트워크 검사 화면이나 진단 자료를 공유하기 전에 서버, 사용자 이름, 비밀번호 및 미디어 경로를 가리세요.

자동 로그인 정보는 평문이므로 TV, 앱 저장소 또는 개발자 도구에 접근할 수 있는 사람이 저장된 계정을 읽을 수 있습니다. 다른 사람에게 공유 TV를 넘기기 전에 저장된 계정을 삭제하세요. 로컬 PIN이나 소프트웨어는 절대적인 보안을 보장하지 않습니다.

보관 기간과 정보 관리

  • Hesap → Hesabı değiştir / sıfırla(계정 → 계정 변경/초기화)는 저장된 서버 주소, 사용자 이름 및 비밀번호를 제거합니다. 설정된 PIN이 있으면 확인을 요청할 수 있습니다. 이 작업은 별도로 저장된 카테고리, PIN, 화면 비율 또는 탐색 설정을 모두 삭제하지는 않습니다.
  • 카테고리 화면의 Düzenle(편집)에서 숨김 설정이나 잠금을 변경하거나 PIN’i ve kategori kilitlerini kaldır(PIN 및 카테고리 잠금 제거)를 선택할 수 있습니다. 기존 PIN이 있으면 확인합니다.
  • 화면 비율과 탐색 간격은 플레이어 설정에서 변경할 수 있습니다.
  • 앱 데이터를 완전히 제거하려면 TV가 지원하는 앱 데이터 관리 절차를 사용하세요. 가능한 방법과 실제 데이터 유지 동작은 TV 모델 및 소프트웨어에 따라 다릅니다. 앱을 제거하는 것만으로 모든 데이터가 반드시 삭제된다고 보장하지 않습니다. 제공업체 서버에 저장된 계정 정보는 해당 제공업체에 문의하세요.

저장된 로그인 정보는 계정을 변경·초기화하거나 운영체제가 앱 데이터를 제거할 때까지 남아 있을 수 있습니다. 별도 설정과 PIN 검증 기록은 해당 설정을 변경·제거하거나 앱 데이터가 제거될 때까지 남아 있을 수 있습니다. 앱은 자체적인 자동 만료 기간이나 게시자에 의한 원격 삭제 서비스를 제공하지 않습니다. 임시 카테고리 잠금 해제 권한은 홈 화면으로 돌아가거나 앱에서 벗어날 때 해제됩니다.

지원 요청 및 방침 변경

게시자에게 이메일 또는 전화로 문의하기로 선택하면 제공한 연락처와 메시지 내용을 요청에 응답하기 위해 사용할 수 있습니다. 메시지를 처리하는 이메일·전화 서비스 제공자는 해당 서비스의 정책에 따라 정보를 처리할 수 있습니다. 지원 메시지는 요청 처리에 필요한 동안 또는 적용되는 보관 의무가 있는 동안 남아 있을 수 있으며 고정된 자동 삭제 기간을 약속하지 않습니다. 지원 요청에 제공업체 비밀번호, PIN 또는 개인 미디어 URL을 포함하지 마세요.
